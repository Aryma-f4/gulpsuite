# Target issue definitions

Open **Target → Issues** to browse Gulpsuite's bundled, offline reference catalog. The catalog describes issue types; seeing an entry here does not mean it was found in your project.

1. Select a definition in the left table. The right pane displays its description, remediation, references, and classifications when available.
2. Click **Name**, **Typical severity**, or **Type index** to sort. Click the same header again to reverse the order.
3. Click a row or tab to the table, then press **↑** or **↓** to move through the displayed order. The table keeps the selected row in view and updates the details as you navigate.

**Project findings** opens the current project's findings and evidence. Choose **Issue definitions** to go back. **Open in browser** opens the public reference on PortSwigger's site.
