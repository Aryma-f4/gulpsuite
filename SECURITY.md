## Reporting a Vulnerability

If you discover a security vulnerability within Gulpsuite itself (such as a parser flaw, certificate generation issue, or auto-updater verification bug), please report it privately via [GitHub Security Advisories](https://github.com/Aryma-f4/gulpsuite/security/advisories/new) rather than opening a public issue.

## Responsible & Authorized Use

Gulpsuite is designed strictly for authorized web application security testing, bug bounty hunting within program scope, penetration testing engagements, and security research. Always obtain explicit permission before scanning or intercepting traffic for any target.
